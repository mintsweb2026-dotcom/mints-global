# Build & Maintenance Scripts

This directory contains automated build pipeline tools, image optimization pipelines, and developer maintenance utilities for the Mints Global web platform.

---

## 🏗️ 1. Build & CI/CD Pipelines (Active)

These scripts run as part of the core build process defined in `package.json`:

| Script | Command | Purpose |
|---|---|---|
| **`generate-sitemap.ts`** | `npm run prebuild` | Automated generator for [`public/sitemap.xml`](../public/sitemap.xml). Scans routes, sets canonical base URLs, priorities, and change frequencies. |
| **`prerender-ssr.js`** | `npm run build` | Headless SSR pre-renderer. Boots the server bundle (`vite build --ssr`), iterates through all public routes, and produces static pre-rendered HTML files for instant TTFB and search engine crawling. |

---

## 📊 2. Quality & SEO Telemetry

| Script | Command | Purpose |
|---|---|---|
| **`seo-report.ts`** | `npm run seo-report` | Comprehensive technical SEO audit tool. Validates canonical tags, Open Graph images, Twitter cards, heading hierarchies (H1/H2), and JSON-LD structured schemas (`Organization`, `Service`, `FAQPage`). |
| **`verify-ssr.mjs`** | `node scripts/verify-ssr.mjs` | Verifies that static HTML generated by the SSR builder matches expected client routes without hydration mismatches. |
| **`verify-live-audit.js`** | `node scripts/verify-live-audit.js` | Live production health checker for edge responses, SSL, and canonical redirection. |
| **`comprehensive-audit.mjs`** | `node scripts/comprehensive-audit.mjs` | Full-site Lighthouse and technical compliance auditor. |

---

## 🖼️ 3. Image Optimization Pipeline

Powered by `sharp` to produce modern high-efficiency `.webp` assets:

| Script | Command | Purpose |
|---|---|---|
| **`optimize-images.ts`** | `npm run optimize-images` | Automated scan across `public/images/`, compressing raster assets into responsive WebP formats (`400w`, `800w`, `1200w`, `1920w`). |
| **`optimize-hero-image.cjs`** | `node scripts/optimize-hero-image.cjs` | Generates 4K, 2K, and responsive breakpoint variants for the homepage hero image. |
| **`crop-favicon.js`** | `node scripts/crop-favicon.js` | Generates web app icons and favicon assets from master brand files. |
| **`optimize-*-thumbnail.cjs`** | `node scripts/...` | Dedicated asset generators for specific practice areas (Cybersecurity, Marketing, Globe, Headquarters). |
